# Canon D

> Целью обучения является не вооружение знаниями, не накопление их, а формирование умения действовать со знанием дела.
> Пётр Яковлевич Гальперин.

> Концептуального знания не достаточно. У вас должна быть убеждённость, происходящая из собственного опыта.
> Максим Дорофеев.

Консольная утилита для формирования практического навыка написания кода. Позволяет заучивать наизусть и тренировать набор на клавиатуре типовых конструкций разных языков программирования. Также позволяет заучивать сигнатуры и применение библиотечных функций разных языков программирования. 

Работает в двух режимах:
- как клавиатурный тренажёр,
- как карточки для [интервального повторения](https://ru.wikipedia.org/wiki/Интервальные_повторения).


## Смысл названия

> Канон (искусство) — совокупность норм и правил в искусстве.

> Канон (наука) — совокупность основополагающих законов, норм и методов в научных знаниях.

Canon D -- Canon for Development -- основополагающие базовые навыки программиста.

А ещё Canon D (Канон ре-мажор) -- это широко известное произведение немецкого композитора Иоганна Пахельбеля. По нему сделано тысячи разных каверов. Например, [этот в стиле Rock](https://www.youtube.com/watch?v=XZgiNnGB8m4).


## А зачем это, когда есть IDE и ИИ?

Мы тренируем мозг примерно так же, как спортсмены тренируют мышцы -- с помощью упражнений, которые создают искусственную нагрузку. Спортсмены бегают и подымают тяжести. Люди умственного труда запоминают факты и решают задачи.

IDE и ИИ не отменяют необходимость тренировать свой естественный интеллект. 


## Использование

```
$ ./canon_d --limit=10 ./decks/golang.md 
```

Карточки для изучения -- обычные markdown файлы. См [decks/golang.md](./decks/golang.md).

Можно и нужно делать свои карточки под себя.


## Планы на будущее

Пока не реализовано интервальное повторение как таковое, но оно будет.

Более сложный формат карточек, чтобы там была и сигнатура функции, и её описание, и примеры использования. Но чтобы не нужно было весь текст вводить с клавиатуры, а только некоторую его часть. Например, сигнатуру и 1 из нескольких примеров использования.

Отслеживания прогресса обучения, отчёты. 

Многопользовательская веб-версия.
