# Canon D

Интервальное повторение как в **Anki** плюс запоминание через действие, плюс клавиатурный тренажёр.

Anki -- пассивное интервальное повторение.
Canon D -- активное интервальное повторение.

В названии два смысла:
- Canon for Development -- базовые навыки программиста
- Канон ре мажор - Пахельбель (Canon in D - Pachelbel)
